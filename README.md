# Pointer Based Algorithms

This README contains detailed documentation of various C programs used in the PointerBasedAlgorithms repository.

## Programs

### 1. createArray.c
- **Description**: This program demonstrates how to create and initialize an array using pointers.
- **Usage**: Compile and run to see the output of the created array.

### 2. findMax.c
- **Description**: This program finds the maximum element in an array using pointer arithmetic.
- **Usage**: Provide an array to find the maximum value.

### 3. fizzBuzzVersion1.c
- **Description**: Implements the FizzBuzz problem solution for numbers from 1 to 100.
- **Usage**: Compile and run to see FizzBuzz outputs.

### 4. fizzBuzzVersion2.c
- **Description**: A more optimized version of the FizzBuzz solution.
- **Usage**: Same as the first version, but optimized for performance.

### 5. maxAndMin.c
- **Description**: This program finds both the maximum and minimum elements in an array.
- **Usage**: Execute to display both values from the provided array.

### 6. mirrorAmatrix.c
- **Description**: Mirrors a given 2D matrix (flips it around its vertical axis).
- **Usage**: Compile and run with a defined matrix.

### 7. reverseArray.c
- **Description**: Reverses the order of elements in an array.
- **Usage**: Execute and observe the reversed output.

### 8. storingRandomNum.c
- **Description**: Generates and stores random numbers in an array.
- **Usage**: Compile and run to see the generated random numbers.

### 9. stringReverser.c
- **Description**: This program reverses a given string using pointers.
- **Usage**: Input a string to see the reversed version.

### 10. sumArray.c
- **Description**: Calculates the sum of elements in an array using pointers.
- **Usage**: Execute to get the sum of the defined array.

### 11. swap.c
- **Description**: Swaps two numbers using pointers.
- **Usage**: Provide two numbers to swap them.

## Conclusion

This documentation provides a brief overview of each program in this repository, you can explore the code for more details on implementation.
